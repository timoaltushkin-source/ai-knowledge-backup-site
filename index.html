AI Knowledge Backup

Личный инструмент для резервного копирования выбранных файлов Google Drive на компьютер владельца с помощью rclone.

Как используется доступ

Подключение выполняется через авторизацию Google. Приложение запрашивает доступ только для чтения: просмотра метаданных и скачивания файлов. Оно не изменяет и не удаляет исходные файлы в Google Drive.

Инструмент предназначен для личного использования владельцем. Этот сайт содержит только описание приложения; файлы резервных копий через него не передаются.
